# csv-data-analyzer
CSV Data Analyzer

## About the Project

CSV Data Analyzer is a beginner-friendly Python project that uses the Pandas library to read and analyze student data stored in a CSV file.

## Dataset

The sample dataset contains these columns:

- Name
- Python
- SQL
- Excel

## Features

- Reads student records from a CSV file.
- Displays the student data in a tabular format.
- Shows the number of students in the dataset.
- Displays the column names.

## Technologies Used

- Python 3
- Pandas
- CSV files

## Project Files

- "csv_analyzer.py" — Python script for analyzing the dataset.
- "students.csv" — Sample student dataset.
- "requirements.txt" — Python dependency list.

## Installation

1. Install Python 3.

2. Install Pandas:
   
   pip install pandas

3. Download or clone this repository.

4. Open the project folder in VS Code.

## How to Run

Run the Python script:

python csv_analyzer.py

If your Python file has a different name, use that filename in the command.
