# csv-data-analyzer
A beginner-friendly Python project that analyzes student data from a csv file using pandas
## Description
A beginner-friendly Python project that analyzes student marks
stored in a CSV file using the Pandas library.

## Features
- Reads student data from a CSV file
- Displays the dataset and column names
- Calculates each student's average marks
- Identifies the student with the highest average
- Calculates average marks for each subject

## Requirements
- Python 3
- Pandas

## Installation
Install Pandas:

    python -m pip install pandas

## How to Run
Run this command in the project folder:

    python data_analyzer.py
